MaxPy Studio

A platform that generates Max for Live audio plugins from plain text descriptions. Its agent turns natural language into a Python intermediate representation via the open source MaxPyLang library, then compiles it to Max MSP and Max for Live devices. It reached 60+ users and led to a peer-reviewed paper on how people work with intermediate representations in LLM-assisted audio programming.

Python LLM Max MSP DSL
